# abrain:lint

규칙은 `AGENTS.md`의 공통 규칙과 아래 "기준 절차"를 따른다. 기준 절차는 `AGENTS.md`에서 옮겨 왔고, 이 스킬의 나머지는 그 실행 순서, 자동 수정 범위, 보고 형식이다.

## 기준 절차

다음을 찾는다:

- **모순**: 같은 대상의 같은 속성에 대해 페이지끼리 다르게 말하는 곳. 양쪽 문장을 그대로 인용할 수 있을 때만 보고한다. 시간이 지나 바뀐 것(일정 변경 등)은 모순이 아니라 갱신 누락이다.
- **낡은 서술**: 더 새로운 소스가 있는데 반영되지 않은 내용.
- **중복 페이지**: 같은 대상을 다루는 페이지. 내용을 한쪽으로 합치고, 다른 쪽은 지우지 말고 합친 페이지로 가는 링크 한 줄만 남긴다.
- **링크**: 깨진 링크, 들어오는 링크가 없는 페이지, 여러 번(3회 이상) 언급되지만 페이지가 없는 대상, index에 빠진 페이지.
- **미결**: 기한이 지난 열린 항목, 30일 넘은 `pending` 결정.
- **출처**: 출처 없는 서술. 그리고 최근 페이지 5개를 골라 인용한 출처가 실제로 그 내용을 담고 있는지 `raw/`와 대조한다.
- **용어와 화자**: `(표기 미확인)`이 남은 곳, 용어집의 틀린 표기가 페이지에 남은 곳, 이름이 미확정인 참여자. 목록으로 모아 다시 묻는다.
- **미처리 원본**: `raw/`에 있지만 ingest되지 않은 파일.

깨진 링크, index 누락 같은 기계적 문제는 바로 고친다. 판단이 필요한 것은 고치지 않고 보고한다. 보고는 항목별 "발견 / 수정 / 남음" 표로 하고, 더 알아볼 질문이나 넣으면 좋을 소스를 제안한 뒤 log에 기록한다.

기계 점검은 `python3 .claude/skills/abrain/scripts/lint-scan.py`로 먼저 돌린다 (읽기만 한다).

## 1. 기계 점검

```bash
date +%Y-%m-%d
.claude/skills/abrain/scripts/lint-due.sh
python3 .claude/skills/abrain/scripts/lint-scan.py
```

`lint-scan.py`는 읽기만 한다. 깨진 링크, 파일명 중복, index 누락, 들어오는 링크 없는 페이지, frontmatter 문제, 기한 지난 열린 항목, 30일 넘은 pending 결정, 낡은 서술 후보, `(표기 미확인)`, 용어집의 틀린 표기, 미확정 참여자, 미처리 원본을 출력한다. 스크립트가 실패하면 같은 항목을 grep으로 직접 찾는다.

## 2. 판단 점검

스크립트가 못 하는 것을 직접 한다.

- **모순** — 같은 대상의 같은 속성을 다르게 말하는 페이지. 양쪽 문장을 그대로 인용할 수 있을 때만 보고한다. 일정이 바뀐 것은 모순이 아니라 갱신 누락이다.
- **낡은 서술** — 스크립트의 "낡은 서술 후보"를 열어, 더 새 source의 내용이 페이지에 실제로 빠졌는지 확인한다.
- **중복 페이지** — 이름은 달라도 같은 대상인 페이지 (한글/영문, aliases 겹침).
- **페이지가 필요한 대상** — 깨진 링크 중 "3곳 이상"이거나, 링크 없이 3개 이상 페이지에서 언급되는 이름.
- **출처** — 출처 `([[...]])` 없는 사실 문장. 최근 `updated` 페이지 5개를 골라 인용한 출처를 `raw/_extracted/`·`raw/`와 대조한다.

## 3. 고치기

| 바로 고친다 (기계적) | 고치지 않고 보고한다 (판단 필요) |
|---|---|
| 깨진 링크 중 대상이 분명한 것 (표기 차이, aliases로 확인됨) | 대상이 불분명한 깨진 링크 |
| index 누락 추가, index의 없는 페이지 줄 삭제 | 모순, 어느 쪽이 맞는지 |
| frontmatter 누락 필드 중 본문에서 확인되는 것 (`type`, `updated`) | 중복 페이지 합치기 (합치는 쪽 제안까지) |
| 용어집에 있는 틀린 표기를 확정 표기로 교체 | 새 페이지 만들기 |
| 원본과 대조해 명백히 틀린 인용 출처 수정 | 기한 지난 할 일의 완료 여부, pending 결정 정리 |

- 페이지를 지우지 않는다. 중복은 사람이 동의하면 한쪽으로 합치고 다른 쪽에는 합친 페이지로 가는 링크 한 줄만 남긴다.
- 고친 페이지는 `updated:`를 오늘로 바꾼다.

## 4. 보고와 기록

모든 항목을 표에 적는다. 문제가 없어도 0으로 적는다.

```

| 낡은 서술 | | | |
| 중복 페이지 | | | |
| 깨진 링크 | | | |
| 들어오는 링크 없음 | | | |
| 페이지 필요한 대상 | | | |
| index 누락 | | | |
| frontmatter | | | |
| 출처 없음·출처 불일치 | | | |
| 기한 지난 할 일 | | | |
| 30일 넘은 pending 결정 | | | |
| 미확인 용어 | | | |
```

- 미확인 용어는 `AGENTS.md`의 용어 확인 형식으로, 미확정 화자는 `.claude/skills/abrain/skills/ingest/SKILL.md`의 "참석자 확인 형식"으로 한 번에 묻는다. 화자를 물을 때는 전사 원문(`raw/_extracted/`)에서 발언을 다시 골라 그 형식을 지킨다.
- 미처리 원본이 있으면 `/abrain:ingest`로 넣을지 묻는다.
- `wiki/log.md` 맨 아래에 반드시 추가한다. 이 줄이 다음 lint 권고의 기준이다:

```
## [YYYY-MM-DD] lint | 발견 N, 수정 M, 남음 K
- 수정: [[...]], [[...]]
- 남음: 모순 1, 중복 1, 미확인 용어 2
```
