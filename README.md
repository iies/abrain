# abrain

회의록, 문서, 녹음을 넣어 두면 AI가 읽고 정리해 **나만의 위키**를 만들어 줍니다.
사람은 자료를 넣고 질문만 하면 됩니다.

## 왜 필요한가요

회의와 문서는 매주 쌓이는데, 한 달 뒤에는 이런 질문에 답하기 어렵습니다.

- "결제 개편 건 지금 어디까지 왔지?"
- "아직 결정 안 된 사안 뭐 있어?"
- "출시일을 왜 12월 15일로 미뤘더라?"
- "내일 김OO 1:1 전에 알아야 할 것 정리해줘"

abrain은 이런 질문에 **어느 회의, 어느 문서에서 나온 말인지** 근거를 붙여 답합니다.

## 어떻게 해결하나요

```
내가 넣는 것              AI가 하는 일                내가 얻는 것
회의록, 문서, 녹음,   →   읽고, 요약하고,         →   결정 / 사람 / 프로젝트 /
영상, 링크                서로 연결하고, 갱신한다       주제별로 정리된 위키
```

- **쌓이지 않고 갱신됩니다.** 회의가 열 번 있어도 프로젝트 페이지 하나에 현재 상황이 정리됩니다.
- **모든 내용에 출처가 붙습니다.** 원본은 `raw` 폴더에 그대로 보관되어 언제든 대조할 수 있습니다.
- **바뀐 사실을 숨기지 않습니다.** "이전: 12월 1일 → 현재: 12월 15일"처럼 표시합니다.

## 시작하기

준비물은 **Mac**, **[Homebrew](https://brew.sh)**, 그리고 **Claude Code** 또는 **Codex** 중 하나입니다.

1. **설치** — 공유받은 abrain 압축 파일을 풉니다. 터미널을 열어 `cd `(띄어쓰기 한 칸)를 입력하고 abrain 폴더를 터미널 창에 끌어다 놓은 뒤 Enter. 이어서 `./INSTALL.sh`를 실행합니다.
   도중에 음성 인식 모델(약 4.6GB)을 받을지 묻습니다. 녹음·영상을 넣을 계획이면 `y`, 아니면 Enter.
2. **실행** — 같은 터미널에서 `claude`(또는 `codex`)를 입력합니다. "이 폴더를 신뢰하시겠습니까?"에는 **승인**합니다.
3. **내 소개** — `온보딩`이라고 입력하고 묻는 말에 아는 것만 답합니다. 이름 말고는 건너뛰어도 됩니다.
4. **첫 자료 넣기** — 파일을 대화창에 끌어다 놓고 `정리해줘`라고 입력합니다.
5. **첫 질문** — 정리가 끝나면 궁금한 것을 물어봅니다.

## 매일 이렇게 씁니다

평소 말하듯이 요청하면 됩니다.

| 하고 싶은 일 | 이렇게 말합니다 | 스킬 (Claude Code / Codex) |
|---|---|---|
| 자료 넣기 | 파일을 끌어다 놓거나, 내용을 붙여넣거나, 링크를 주고 "정리해줘" | `/abrain:ingest` / `$abrain-ingest` |
| 물어보기 | "결제 개편 건 지금 어디까지 왔지?" | `/abrain:query` / `$abrain-query` |
| 틀린 내용 고치기 | "그거 틀렸어, 출시일은 12월 20일이야" | `/abrain:query` / `$abrain-query` |
| 위키 점검 (주 1회 권장) | "점검해줘" | `/abrain:lint` / `$abrain-lint` |
| 아침에 놓친 것 확인 (매일) | "모닝" 또는 "오늘 뭐 챙겨야 해?" | `/abrain:morning` / `$abrain-morning` |

말로 해도 같은 스킬이 실행됩니다. AI가 요청을 다른 뜻으로 알아들을 때는 스킬 이름을 직접 입력하면 확실합니다. 처음 한 번 하는 온보딩의 스킬은 `/abrain:onboarding` / `$abrain-onboarding`입니다.

**모닝 브리핑**은 Claude나 Codex에 연결해 둔 도구(메일, Slack, Jira, Confluence, Google Drive, 캘린더 등)와 위키를 훑어 지난 브리핑 이후 놓친 것, 오늘 챙길 것, 오늘 회의 준비, 날씨를 한 장으로 알려 주고 위키에 남깁니다. 밖의 도구는 읽기만 하며, 답장을 보내거나 무엇을 고치지 않습니다.

정리 도중 AI가 용어 표기("모아 / 모와 중 어느 쪽이 맞나요?")나 녹음 속 발언자를 되물을 수 있습니다. 모르면 "모르겠다"고 답해도 됩니다.

## 세 가지 약속

- **`raw` 폴더는 원본 보관함입니다.** 직접 지우거나 이름을 바꾸지 마세요.
- **`wiki` 폴더는 AI가 쓰는 곳입니다.** 직접 고치지 말고 "이 부분 틀렸어, 고쳐줘"라고 말하세요.
- **자료는 내 컴퓨터에만 저장되지만, 정리 과정에서 내용이 Claude 또는 Codex 서비스로 전송됩니다.** 회사의 AI 도구 사용 정책에 맞는 자료만 넣으세요.
